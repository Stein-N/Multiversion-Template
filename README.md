## Multiversion Template

Based on the work of [Jaredlll08's](https://github.com/jaredlll08) [Multiloader Template](https://github.com/jaredlll08/MultiLoader-Template).
With the addition of the support for 2 Minecraft versions in one project.

### Stable
The stable version describes the current version of Minecraft where most of the ModPacks get created and most of 
Mod Creators silently agree they use that version as an "LTS" version.

### Latest
The latest version of Minecraft

### Modloader
This Template only supports Fabric and Neoforge because of personal reasons and the slow and clunky updates for forge
and all the Tools.
